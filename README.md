# 高機能画像編集ツールボックス (Image Editor Toolbox)

このプロジェクトは、Webブラウザ上で高度な画像編集を実現するためのReact / TypeScriptコンポーネント群です。以下の4つの主要機能を中心に、強力なクライアントサイド画像処理と快適な操作環境を提供します。

1. **画像クロップ機能:** 四角形や円形に加え、多角形やフリーハンドなど自由な形状での精密切り抜きに対応。Sobelフィルタによる輪郭自動吸着（マグネットモード）や反転クロップ、プレビュー上での頂点選択操作を統合しています。
2. **PDF生成・抽出機能:** 複数の画像をPDFに変換するだけでなく、既存のPDFファイルから画像を自動抽出して取り込んだり、リスト内の全画像をZIPアーカイブにまとめて一括ダウンロードしたりできます。
3. **画像結合機能:** ズーム・パンに対応した広大なキャンバス上に画像を自由に配置・合成。動的グリッド、吸着スマートガイド、画像一覧トレイによる自動フォーカス、配置領域の余白自動トリミングWebPエクスポートを搭載しています。
4. **ペイント機能:** 画像や複数ページのPDFドキュメント上に直接ペンや蛍光ペンで注釈・書き込みが可能。3タイプ（手書き線 / 画像オブジェクト / 両方）の境界認識塗りつぶし、直線スナップ、ブラシカーソル追従プレビュー、PDF/WebPエクスポートに対応しています。

すべての機能は、[GalleryContext.tsx]の**共有ギャラリー**を介してシームレスに連携でき、画面間での画像受け渡しが簡単に行えます。また、オプショナルな `Socket.IO` サーバーによる**リアルタイム同期機能**も備えています。

---

## ① 主な特徴

* **多機能なインブラウザ完結処理:** すべての画像編集、PDF生成、画像抽出、ZIP生成、ペイント・塗りつぶし処理がクライアントサイドのブラウザ上で安全かつ高速に完結します。
* **クライアントサイド画像最適化:** Web Worker と `@jsquash/webp` を組み合わせ、メインスレッドをブロックすることなく高品質な WebP 変換を実行。データ転送量とメモリ使用量を劇的に節約します。
* **デスクトップアプリ級の操作インタラクション:** ズーム＆パン、スナップスマートガイド、Undo/Redo、直線スナップ（Shiftキー）、ブラシカーソル追従プレビューなど、快適な編集体験を提供します。
* **共有ギャラリーによる画面間連携:** クロップ・抽出・結合・ペイントで作成した画像を共有ギャラリーに保管し、ワンクリックで別の機能へ取り込んでシームレスに加工を継続できます。
* **ダーク / ライトテーマ切り替え:** ヘッダーから瞬時にテーマを切り替え可能。ユーザーの好みに合わせた作業環境を提供します。
* **ヘルプ＆操作ガイド内蔵:** ヘッダーのヘルプボタンからいつでも画面に応じた操作マニュアルやショートカット一覧を確認できます。
* **モバイル＆タッチ対応:** ピンチズーム、二本指ドラッグ（パン）、タッチ操作でのドラッグ＆ドロップ並び替えに対応しています。

## ② 機能詳細

### 1. 画像クロップ機能 ([CropperComponent.tsx])

元画像のオリジナル解像度を保持したまま、自由な形状で精密に切り抜くためのコンポーネントです。

* **自由度の高いクロップ形状:**
  * `四角形 (Rect)`、`円形 (Circle)`
  * 任意の頂点をクリックして囲む `多角形 (Polygon)`
  * マウスやタッチ操作で自由になぞる `フリーハンド (Path)`
* **マグネットモード（エッジ吸着）:**
  * Sobelフィルタを用いたリアルタイム輪郭検出 ([edgeDetection.ts]) により、境界線に近づくと頂点が自動でエッジへ吸着します（感度スライダーで調整可能）。
* **精密な調整機能:**
  * **プレビュー上の頂点選択:** クロップ結果のプレビュー画像に表示される頂点マーカーを直接クリックして頂点を選択可能。
  * **0.5px単位の微調整:** 選択中の頂点を上下左右ボタンで微細に移動・調整・削除できます。
  * **各辺の微調整:** 四角形・円形クロップ時、上辺・右辺・左辺・下辺を個別の微調整ボタンで微細に変更可能。
  * **滑らかさ補正:** フリーハンド（パス）描画時はスライダーで曲線のスムージング（デシメーション）度合いを調整できます。
* **反転クロップ:**
  * 選択範囲の内側を残すだけでなく、**選択範囲をくり抜いて外側を残す**設定が可能です。
* **高解像度エクスポート & ギャラリー連携:**
  * 表示用の縮小表示に影響されず、オフスクリーンの Fabric キャンバスを用いて元画像のオリジナル解像度でクロップ処理を施します。
  * 切り抜いた画像はWebP形式でダウンロード、または「共有ギャラリー」へ直接保存できます。

### 2. PDF生成・抽出機能 ([PdfComponent.tsx])

複数の画像を並べ替えてPDF化する機能に加え、PDFから画像を取り出す双方向のドキュメント画像ツールです。

* **PDFインポート（画像抽出）:**
  * 既存のPDFファイルを選択すると、`pdf-lib` を用いてPDF内部の画像オブジェクト（`Subtype: Image`）を解析し、自動的に画像として抽出して編集リストに展開します ([usePdfExtractor.ts])。
* **ドラッグ＆ドロップによる並べ替え:**
  * `@dnd-kit` を使用したスムーズな並べ替え。
  * **複数選択状態での一括ドラッグ＆ドロップ**に対応。Shiftクリックによる範囲選択やCtrl/Cmdクリックによる個別選択を行い、選択バッジ付きでまとめて移動できます。
* **画像ZIP一括ダウンロード:**
  * リスト内の全画像を、`jszip` と `file-saver` を使ってブラウザ上でZIPアーカイブファイル（`images.zip`）にまとめて一括ダウンロードできます。
* **画像自動最適化・圧縮パイプライン:**
  * アップロードされた画像を自動的にWebP変換後、PDF埋め込み用に適切な解像度・品質制限を考慮したJPEG圧縮を行い、ファイルサイズとメモリ消費を最適化します。
* **進捗フィードバック:**
  * 画像アップロード、PDF抽出、PDF生成、ZIP圧縮の各プロセスで、プログレスバーと進捗率（%）を視覚的に表示します。

### 3. 画像結合機能 ([CombinerComponent.tsx])

広大なキャンバス上に複数の画像を自由に配置・コラージュし、独自のレイアウトを作成するための多機能キャンバスツールです。

* **動的グリッド表示 (マス目):**
  * ズーム倍率と選択中のテーマ（ダーク/ライト）に応じて適切な間隔・カラーで自動スケーリングする背景グリッド線を描画。編集時の正確な配置をサポートします（エクスポート時には自動で非表示になります）。
* **スナップ＆スマートガイドライン:**
  * 画像の移動・変形時、他のオブジェクトのエッジや中心線に合わせて自動吸着。吸着時には赤いガイドラインが表示され、スライダーで線の太さを自由に調整できます。
* **サイドバー「画像一覧」トレイ:**
  * 左サイドバーの画像一覧からキャンバス上の配置画像を確認可能。アイテムをクリックすると、対象の画像がキャンバス中央に表示されるよう自動でビューポートがスクロール＆ズーム（フォーカス）します。一覧からの名前変更や削除も可能です。
* **レイヤー順序操作:**
  * オブジェクトの重なり順（最前面・前面・背面・最背面）をワンクリックで変更できます。
* **余白自動トリミングエクスポート:**
  * キャンバス全体の広大な余白は自動カットされ、**配置された画像群が占める最小矩形領域だけをぴったりトリミングした高画質WebP画像**としてエクスポート・ギャラリー保存します。
* **リアルタイム情報表示:**
  * 選択中オブジェクトの幅・高さ（px）およびキャンバスの現在ズーム倍率（%）をリアルタイム表示します。

### 4. ペイント機能 ([PaintComponent.tsx])

画像や複数ページのPDFドキュメント上に直接ペンで手書き描画したり、高度な塗りつぶし・注釈を行えるツールです。

* **多彩な描画ツール:**
  * **ペン:** 滑らかなフリーハンド描画。
  * **蛍光ペン:** 下地の文字や画像を透過する半透明ハイライト描画。
  * **消しゴム:** なぞった部分だけを削る「ピクセル消去」と、線全体を1本丸ごと消す「ストローク消去」の2モードを搭載。
  * **直線スナップ機能:** <kbd>Shift</kbd> キーを押しながらドラッグすることで、ペン・蛍光ペン・消しゴムで正確な直線（水平・垂直・45度斜め）をリアルタイムに描画できます。
* **3タイプの境界認識塗りつぶし (Flood Fill):**
  * **手書き線:** 手書きの線で囲まれた閉じた領域の内側を塗りつぶし（背景画像は無視）。
  * **画像オブジェクト:** 下地画像内の物体の輪郭境界を自動認識して塗りつぶし（手書き線は無視）。
  * **手書き＋画像:** 手書き線と画像オブジェクトの両方を境界線として認識して塗りつぶし。
  * **詳細調整スライダー:** 塗りつぶし許容度（輪郭認識感度）、不透明度、線の途切れ許容（gap closing: 線の隙間があっても漏れ出さずに塞いで塗る幅）を細かく制御可能。
* **ブラシカーソル追従プレビュー:**
  * キャンバス上でブラシの実際の太さ・色・透明度を反映した円形カーソルがリアルタイムに追従し、描画前に仕上がりを確認できます。
* **カラーパレット & 自由選択:**
  * 厳選された20色のプリセットパレットに加え、HTML標準のカラーピッカーによる自由なカスタム色の指定に対応しています。
* **複数ページPDF対応:**
  * PDFファイルを読み込んだ場合、ページ送りバー（前へ/次へ）でページを切り替えながら個別のページごとに注釈を書き込むことができます。
* **多彩なエクスポート:**
  * 現在の描画を合成した高画質WebP画像の保存、複数ページをまとめたPDFドキュメントの出力、共有ギャラリーへの保存に対応しています。

## ③ アーキテクチャと共通機能

### 共有ギャラリー ([GalleryContext.tsx])
React の Context API を用いた状態管理システムです。各画面で作成した画像を一時保存し、画面間でシームレスに受け渡すことができます。グリッド表示とリスト表示の切り替え状態は `localStorage` に保持されます。

### ダーク / ライトテーマ対応
ヘッダーのテーマ切り替えボタンから、ダークテーマとライトテーマを瞬時に切り替えられます。設定は `localStorage` に自動保存されます。

### ヘルプ＆操作ガイド ([HelpModal.tsx])
ヘッダー右上のヘルプアイコンから、全画面共通および各画面別の詳細な操作マニュアル、ショートカット一覧をいつでも参照できます。現在開いている画面に応じたタブが自動で開きます。

### クライアントサイド画像最適化 ([webpConverter.ts] / [webp.worker.ts])
Web Worker を用いてバックグラウンドで `@jsquash/webp` を実行。ImageData のバッファを Transferable オブジェクトとして転送することで、メインスレッド（UI）を一切固めることなく高速・高品質な WebP 変換を行います。

### リアルタイム同期 ([syncService.ts] / [server.js])
Socket.IOを利用したキャンバス共同編集用の同期基盤です。Fabric.js のオブジェクト情報をシリアライズし、大容量データ送信時は約900KBのチャンクに分割して送受信します。

## ④ 主なショートカット操作

| 操作 | ショートカットキー / アクション | 対象画面 |
| :--- | :--- | :--- |
| **元に戻す (Undo)** | <kbd>Ctrl</kbd> + <kbd>Z</kbd> (Mac: <kbd>⌘</kbd> + <kbd>Z</kbd>) | 全画面共通 |
| **やり直す (Redo)** | <kbd>Ctrl</kbd> + <kbd>Y</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> (Mac: <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd>) | 全画面共通 |
| **ダイアログを閉じる** | <kbd>Esc</kbd> | 全画面共通 |
| **直線スナップ描画** | <kbd>Shift</kbd> + ドラッグ | ペイント画面 |
| **キャンバスのパン（画面移動）** | <kbd>Alt</kbd> + ドラッグ / 二本指ドラッグ | 画像結合、ペイント画面 |
| **キャンバスのズーム** | <kbd>マウスホイール</kbd> / ピンチ | 画像結合、ペイント画面 |
| **複数選択** | <kbd>Shift</kbd> + クリック (範囲選択) / <kbd>Ctrl</kbd> + クリック | PDF画面、画像結合画面 |
